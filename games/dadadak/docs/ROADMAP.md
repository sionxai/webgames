# 다다닥 모드 로드맵

> PRD v1.0 이후 확장 후보. 상태: ✅ 구현됨 / 🔧 설계 완료(구현 대기) / 💡 아이디어.
> 원칙: 모든 모드는 기존 배틀 엔진(서버 권위, 250ms 윈도우, flagged 안티치트)을 재사용한다.
> v1.1 반영 여부의 최종 판단 기준은 PRD와 동일하게 운영 데이터(G1~G4)다.

## ✅ 구현됨 (2026-07-02)

| 모드 | 내용 |
|------|------|
| 무한 딸깍 (홈 히어로 + `/tap`) | 시간 제한 없는 **평생 누적 기록**. 홈 카드 자체가 클리커. 배틀(flagged 제외) 클릭도 자동 합산. 등급: 키보드 스위치 9단계(뽁뽁이→무접점). 일일 적립 상한 5만 |
| 시간 옵션 | 솔로·방 대결에서 **10초/30초/1분** 선택. 랜덤 매치는 10초 고정(매칭 풀 분산 방지). 랭킹은 CPS 기준이라 시간 무관 통합 |
| 대형 방 | 방 최대 인원 8/16/**30명** 선택. 배틀 화면은 상대 그리드 스크롤 |
| 도장깨기 (고스트 대결, `/challenge/[matchId]?p=`) | 기록 보유자가 없어도 그 기록의 **클릭 타임라인이 고스트로 실시간 재생**되어 1:1 대결. 결과 공유 랜딩(`/result`)에 "이 기록에 도전하기" CTA → 공유→유입→재공유 루프. 고스트 기록은 DB에 중복 저장하지 않음 |
| 글로벌 이벤트 매치 (`/event`) | `EVENT_INTERVAL_SEC`(기본 3600초) 주기로 열리는 전국 단일 30초 이벤트 라운드. 홈 배너 카운트다운, 최대 100명 로비, 대인원 sync 최적화 포함 |
| 버스트 모드 | 솔로 3초 순간 최대 CPS 측정. 일반 랭킹·`best_cps`와 분리된 `best_burst_cps` 기록, 랭킹 제외, 완화 임계 26CPS 적용 |
| 일일 미션 | KST 기준 매일 3개 미션, 완료 후 누적 딸깍 보상 지급. E2E 고정용 `MISSION_IDS` 테스트 훅 포함 |
| 서든데스 레이스 | 방 대결 전용 선착순 모드. 50/100클릭 목표에 먼저 도달하면 즉시 종료, 60초 제한 |
| 골든 클릭 | 방 대결 시간제 옵션. score와 원시 클릭 total을 분리해 랭킹·기록 오염 없이 승부만 2배 구간 반영. E2E 고정용 `GOLDEN_WINDOWS_MS` 테스트 훅 포함 |
| 스위치 사운드 팩 | Web Audio 합성 클릭음 9종. 등급별 해금과 사용자 선택 저장 |
| 업적 도감 | 14종 업적을 DB 지연 평가로 멱등 해금. 전용 도감 페이지와 진행 요약 제공 |
| 탭 버튼 스킨 | 등급·업적 조건으로 해금되는 탭 버튼 스킨 8종. 설정에서 선택 저장 |
| 방 QR 초대 | 방 초대 링크를 QR 코드로 표시해 같은 공간에서 빠르게 입장 |
| 딸깍 스트릭 | 홈 방문 기준 KST 연속 출석. 7·30·100일에 누적 딸깍 보너스 지급 |
| 도발 프리셋 | 고스트 도전장 공유에 프리셋 문구를 URL 파라미터 전용으로 붙임. 자유 입력·DB 저장 없음 |
| 주간 리포트 카드 | `/report/[userId]/[week]` 공유 랜딩과 OG 이미지로 주간 배틀 요약 제공 |

- 채팅·이모지 반응 — PRD 비목표(모더레이션 부담) 유지
