## 1. 프로젝트 개요

- **서비스명**: 다다닥 (영문 DADADAK). 도메인 dadadak.kr. 표기 규칙 — 브랜드명·로고에는 "다다닥"만 사용, "딸깍"은 캠페인 카피 전용(브랜드명 사용 금지, 유행어 수명과 브랜드를 분리).
- **무엇을**: 폰 터치 또는 아무 키보드로 참전하는 실시간 클릭 대결 웹앱. 솔로 CPS 측정, 실시간 1:1 매치, 친구 방 대결, 학교/지역/전국 랭킹을 제공한다.
- **누구를 위해**: 키캡 클리커(딸깍이) 유행의 중심인 10~20대. 앱 설치 없이 링크 하나로 진입한다.
- **왜**: 오프라인 딸깍이 유행(촉감 소비)에 "경쟁·기록·공유"라는 온라인 레이어를 얹어 바이럴 확산을 검증한다. 본 웹앱은 사업 1단계 검증 실험이며, 리텐션·바이럴 지표 확인 후 2단계(NFC 키링 → BLE 컨트롤러 굿즈)로 확장한다.
- **핵심 사용자 플로우**: 링크 진입 → 닉네임 입력(3초 온보딩) → 솔로 측정 or 1:1 매치 or 방 참가 → 10초 배틀 → 결과 카드 공유 → 친구 유입

## 5. 기능 명세

### F1. 익명 온보딩 (P0)

**User Story**: 방문자는 회원가입 없이 닉네임만 입력하고 3초 안에 시작할 수 있다.

- **Given** 첫 방문(세션 쿠키 없음) **When** 아무 페이지 진입 **Then** 닉네임 입력 모달이 뜨고, 입력 완료 시 uuid가 발급되어 iron-session 쿠키에 저장된다.
- **Given** 닉네임에 비속어 포함 **When** 제출 **Then** "사용할 수 없는 닉네임이에요" 인라인 에러, 제출 차단.
- **Given** 재방문(쿠키 존재) **When** 진입 **Then** 온보딩 생략, 홈으로 직행.
- 학교/지역 설정은 온보딩에서 받지 않는다. 랭킹 페이지에서 최초 열람 시 선택 유도(스킵 가능).

### F2. 솔로 CPS 측정 (P0)

**User Story**: 사용자는 혼자 10초 클릭 측정으로 자기 기록(CPS)을 확인하고 공유한다.

- **Given** `/solo` 진입 **When** 화면 탭 또는 아무 키 입력 **Then** 3초 카운트다운 후 10초 측정 시작.
- **Given** 측정 중 **When** 터치(touchstart) 또는 키다운(repeat 제외) **Then** 카운트 +1, 버튼 시각 피드백(scale 0.96, 80ms).
- **Given** 10초 종료 **Then** 결과 화면: 총 클릭, CPS, 내 최고기록 갱신 여부, 전국 상위 % 표시, 공유 버튼.
- **Given** 측정 중 탭이 백그라운드 전환(visibilitychange) **Then** 측정 즉시 무효 처리, "화면을 벗어나서 무효 처리됐어요" 안내.

### F3. 실시간 1:1 랜덤 매치 (P0)

**User Story**: 사용자는 버튼 하나로 지금 접속 중인 모르는 상대와 10초 클릭 대결을 한다.

- **Given** `/match`에서 매칭 시작 **When** 대기열에 다른 사용자가 있음 **Then** 3초 내 매치 성사, 배틀 화면 이동.
- **Given** 대기 30초 초과 **Then** "지금은 상대가 없어요" + 솔로 측정/방 만들기 유도 버튼 노출, 대기 유지 여부 선택.
- **Given** 배틀 중 **When** 상대 카운트 갱신 **Then** 250ms 이내 화면 반영 (서버 sync 브로드캐스트 기준).
- **Given** 배틀 중 상대 연결 끊김(5초 무응답) **Then** 상대 카운트 동결, 배틀은 끝까지 진행, 종료 시 정상 판정.

### F4. 초대 링크 1:1 (P0)

**User Story**: 사용자는 링크를 카톡으로 보내 특정 친구와 1:1 대결한다.

- **Given** "친구 초대" 탭 **When** 링크 생성 **Then** `/room/{code}` 형태 URL 클립보드 복사 + OS 공유 시트(Web Share API) 호출.
- **Given** 초대받은 친구가 링크 진입 **When** 닉네임 온보딩 완료 **Then** 같은 방 대기실 입장, 호스트에게 실시간 표시.

### F5. 방 대결 2~8인 (P0)

**User Story**: 반 친구들끼리 방 코드를 공유해 최대 8명이 동시에 대결한다.

- **Given** 방 대기실에 2인 이상 **When** 호스트가 시작 버튼 **Then** 전원 동시 3초 카운트다운 → 10초 배틀 → 순위 결과.
- **Given** 방 인원 = max_players **When** 추가 입장 시도 **Then** "방이 가득 찼어요" 안내, 새 방 만들기 유도.
- **Given** 호스트 이탈 **Then** 입장 순서 다음 사람에게 호스트 자동 승계, 전원에게 토스트 알림.
- **Given** 배틀 중 일부 이탈 **Then** F3과 동일 처리(동결 후 정상 판정).

### F6. 배틀 코어 & 카운팅 프로토콜 (P0)

- 클라이언트는 클릭을 로컬 누적하고 **250ms마다 `battle:tick { delta }`로 전송**한다. 클릭마다 개별 전송 금지(네트워크 폭주 방지).
- 서버는 윈도우당 delta를 검증 후 누적하고, 250ms마다 전원에게 `battle:sync { counts, remainMs }` 브로드캐스트.
- 타이머 권위는 서버. 클라이언트 타이머는 표시용이며 종료 판정은 `battle:end` 수신 시점.
- 입력 인정 규칙: 터치 = touchstart(멀티터치 각각 인정, 두 엄지 허용), 키보드 = keydown(event.repeat === true 무시).

### F7. 안티치트 (P0)

- **Given** 250ms 윈도우 delta > 8 **Then** 해당 윈도우는 8로 절삭(순간 최대 32CPS 허용).
- **Given** 경기 평균 CPS > 20 **Then** 결과는 표시하되 `flagged=1` 저장, 랭킹·최고기록 반영 제외, 결과 화면에 "비정상 입력이 감지되어 랭킹에 반영되지 않아요" 표기. [가정: 임계값 20 — 운영 데이터로 재보정]
- 클라이언트 위변조 대비: 서버 확정 값만 저장·표시. 클라이언트가 보낸 총합은 신뢰하지 않는다.

### F8. 랭킹 (P0)

**User Story**: 사용자는 전국/지역/학교 단위의 일간·주간 CPS 랭킹에서 내 위치를 확인한다.

- **Given** `/rank` 진입, 학교 미설정 **Then** 전국 탭 기본 표시 + "우리 학교 랭킹 보려면 학교 설정" 배너.
- **Given** 학교 검색 **When** 2자 이상 입력 **Then** 정적 학교 목록에서 자동완성(최대 10건).
- 랭킹 산정: flagged=0인 매치의 개인 최고 CPS 기준, 일간(오늘)/주간(월~일). 동률 시 먼저 기록한 쪽이 상위.
- 학교 인증은 하지 않는다(자가 신고). 어뷰징은 Phase 1에서 감수하고 지표만 관찰. [가정]

### F9. 결과 공유 카드 (P0)

**User Story**: 사용자는 배틀 결과를 이미지 카드 링크로 공유해 친구를 유입시킨다.

- **Given** 결과 화면 **When** 공유 버튼 **Then** `/result/{matchId}?p={userId}` 링크가 Web Share API로 공유되고, 해당 URL의 OG 이미지에 닉네임·CPS·승패가 렌더링된다.
- **Given** 공유 링크로 신규 방문 **Then** 결과 요약 + "나도 도전하기" CTA → 온보딩 → 솔로 또는 리매치. 유입은 `invite_joins`로 집계.

### F10. 어드민 지표 (P1)

- `/admin` 비밀번호 게이트(iron-session). 일자별 방문/매치 수/공유 클릭/초대 유입/flagged 비율 테이블. CSV 다운로드. 그래프 없음(표만).

### 9.2 보안·법규 원칙

- **PII 무수집 설계**: 이메일·전화·실명·생년월일을 받지 않는다. 수집 항목은 닉네임(자유 입력)과 선택적 학교/지역뿐. 만 14세 미만 법정대리인 동의 의무(개인정보보호법 제22조의2)는 개인정보 자체를 수집하지 않는 구조로 회피한다. 단, 접속 기록(IP)의 로그 보관 정책은 개인정보처리방침에 고지. [확인필요-비차단 U3: 처리방침 문안]
- 닉네임 비속어 필터: 한국어 비속어 사전 기반 부분 문자열 매칭 + 우회 표기(자모 분리 등) 1차 대응. 완벽을 목표로 하지 않고 신고 없이 어드민 수동 교체 가능하게 한다.
- 세션: iron-session HttpOnly + Secure + SameSite=Lax.
- 레이트 리밋: POST 계열 IP당 분당 30회.
- XSS: 닉네임은 렌더 시 이스케이프(React 기본) + 길이 8자 제한.

    - **모션 프레임(0~3)**: 누름→스쿼시(1, 홀드) / idle 폴짝→점프·착지(2·3). translateY·scale, held/hop 90ms.
    - **표정 6종(neutral·blink·happy·star·proud·sleepy)**: 상태 우선순위 held > 마일스톤(star) > 적립한도(sleepy) > 콤보≥10(happy) > 방치졸림(sleepy) > 깜빡 > 뿌듯(streak) > 평상(neutral). 크로스페이드 140ms.
    - **idle 생명감**: 안쪽 래퍼 숨쉬기(2.6s, transform만) + 4.5~8초마다 깜빡(420ms)·폴짝·뿌듯(3s) 잔동작 + **12초 무입력 시 졸림**(누르면 깸).
    - 모션·표정 프레임 전부 스택·프리로드, opacity 토글. `prefers-reduced-motion`이면 숨쉬기·잔동작 정지(상태 표정은 유지).

### 12.6 모션

- 기본 트랜지션 150ms ease-out
- 배틀 카운터 증가: 숫자 팝(scale 1.0→1.08→1.0, 120ms) — 클릭 쾌감의 핵심, 60fps 유지 필수
- 모드 타일·히어로 탭 컨트롤 pressed: 90~100ms, transform·border-width만 (v1.0.1)
- 딸깍존 이펙트 (v1.0.2): +1 플로터(손끝 좌표·랜덤 드리프트±10px·틸트±5°, 520ms)·탭 리플(360ms, 동시 4개 캡)·콤보 표시(연타 간격 800ms 이내 5연속부터, 끊기면 300ms 페이드)·1,000단위 마일스톤 버스트(520ms, 동시 1개) — **전부 탭 반응형 1회성, transform/opacity만.**
- **홈 마스코트 idle 예외 (v1.0.5)**: "반복 루프 금지"는 홈 캐릭터 웰 하나에 한해 푼다 — 숨쉬기(transform 무한 루프)·잔동작·표정. 근거: 단일 소형 요소의 transform은 GPU 컴포지터에서 60fps·배터리 무해(§2.3-2가 막는 파티클·3D·전면 리페인트 아님), 레퍼런스 Duolingo 정합. `prefers-reduced-motion`에서 정지. 이 예외는 **홈 마스코트에만** 적용 — 다른 화면·요소는 1회성 원칙 유지.
- 승리 연출: 500ms 이내 1회성. 반복 루프 애니메이션 금지(위 idle 예외 제외)
